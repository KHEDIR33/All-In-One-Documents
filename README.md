# All Doc Converter Bot ⚡

A powerful, all-in-one Telegram Bot to convert and manage documents effortlessly.

## 🌟 Features
- 📄➡️📝 **PDF to Word** (`.docx`)
- 📄➡️📊 **PDF to Excel** (`.xlsx`)
- 📝➡️📄 **Word to PDF** (`.pdf`)
- 🖼➡️📄 **Image to PDF** (`.pdf`)
- 📄➡️🖼 **PDF to Images** (`PNG`)
- 🗜 **Compress PDF** (Reduce file size)
- 🔓 **Remove PDF Password** (Unlock protection)

## 🚀 Deployed on
- Render (Python Web Service)
